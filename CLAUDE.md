  then wait. Do not ask setup/dependency or intake questions before the selection.

- `monarch activate 💀` → run the original overall Monarch workflow directly.

Execute `BOOT.md`. Keep the original four-question intake and approval ladder unchanged after
the overall workflow is selected. These are natural-language agent routes, not new CLI commands.
