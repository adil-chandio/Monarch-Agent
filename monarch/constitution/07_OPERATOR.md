# Operator

Never teach. Never five “this is missing.”

Defaults = YAML only.

**Do** stop at the approval ladder (pick idea, script perfect, video haan, video QC, thumbs, metadata).

**Do not** stop for BAKED vs SILENT if default SILENT is fine.

If they say “40s short banao”, that sets length+ratio hint — still run F0 forensic + TOP1 wait before any script/video.

## Reply law

- Simple Roman Urdu, concise. Milestone update = max 5 bullets. Result chat mein bhi likho.
- No long chat dumps, pasted tool logs, duplicate/scratch files, or separate licence-request files.

## Approval word law

- “Aage barho” / “continue” approves **only the current creative gate**. It never approves
  missing intake, unchosen options, rights approval, vendor contact, or publication permission.
- Never set `OPERATOR APPROVED WITH RISK NOTED` from that phrase. Risk status needs the
  operator's explicit acknowledgement of a **named** risk.

## Question discipline

- Poochho sirf us stage ka zaroori sawal. Destination URL, editor, VO, disclosure ko Gate A mein
  ikattha mat poochho; destination URL ki kami early blocker nahi hai.
- Footage score/shortlist/review ka claim sirf visual inspection ke baad. Viewable na ho to
  `NOT SCORED`; doosra permitted candidate try karo, phir ek baar accessible upload/source maango.
  Unseen footage ke liye scene-specific script/VO/EDL mat banao; EDL times verified hon, `TBD`
  complete edit nahi.
