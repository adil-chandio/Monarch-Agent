# Packaging OS — click is a weapon, payoff is a contract

Video ready ≠ upload. Upload is a second product: **the 1-second war on the home feed.**

## Job

Own the thumb + title so the brain cannot keep scrolling. Curiosity, WTF, FOMO, unfinished pattern. Then the video **must pay** or CTR dies next upload.

## Forensic (before any title)

Scrape/study niche winners (later: yt-dlp + captions). For each top video extract:

- Title pattern (open loop, number, forbidden, vs, you-are-wrong)
- Thumbnail: face/pose, object scale, color, empty space, contrast, what is *hidden*
- Promise vs first 8s vs payoff (lie = we never copy)
- Psychology itch: status, fear, revenge, secret, scale, identity
- What they did **not** say (the gap we occupy)

Elevate 10x: same itch, **new** picture, **new** unfinished sentence. Never clone a winning thumb.

## Title law

- One job: force the click **with** a true unpaid debt the video closes.
- Not a label. Not “Top 10 Bear Attacks.”
- Specific > vague. Concrete image in the words.
- Open loop or inverted belief. One surprise, not three.
- No all-caps spam. No fake “GONE WRONG” if it did not.
- Length: scannable on mobile (roughly ≤ 60 chars primary, extra in description).
- Channel language lock (later).

Fail if a stranger would not stop mid-scroll.

## Thumbnail law (stickman)

- Read at **postage-stamp** size.
- One idea. One giant object or one extreme pose. High contrast.
- Face/eyes if we have them: one emotion, oversized.
- Empty third for CapCut headline (never bake text in the model).
- Accent color = channel lock.
- 5 variants (engine M6): reaction close, vs-scale, before/after, object-hero, genre-range.
- Pick by **postage test**, not pretty-test.

## Description / tags / chapters

- First 1–2 lines = title’s second barrel (search + residual curiosity).
- Chapters match scene maths.
- Tags = how real humans search that itch, not keyword stuffing.
- End screen / pinned: later. No “like and subscribe” as the hook.

## Upload

- Default: **private / unlisted draft**. Public only on operator order.
- Package JSON + assets before API.
- No live YouTube scrape/upload in this phase.

## Gate (all must pass)

- [ ] Would you click if you hated this niche?
- [ ] Title + thumb = one sentence, not two different videos
- [ ] Promise is paid in the script
- [ ] Not a clone of a current winner
- [ ] Postage-stamp readable
- [ ] WTF/FOMO without a lie
