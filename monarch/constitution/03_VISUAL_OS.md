# Visual OS (structure — not production)

## Promise

Viewer cannot look away for 1 second. If attention slips, FOMO hits. First **2–3 seconds** must force the rest of the watch.

## Style direction (ours, not a PDF clone)

- Stick-figure / explainer grammar: silhouette bodies, huge contrast, punch zooms, on-screen text as weapon.
- Black / near-black void OR one dominant field. Color is a *signal*, not decoration.
- Motion = meaning. No idle holds. Every frame answers: new info, threat, joke, twist, or proof.
- Premium SFX: whoosh, hit, glitch, bass drop, silence as punctuation — never stock-cartoon spam.
- Voiceover leads the cut. Picture never lags VO; picture never spoils the line.

## Hard bans

- Generic stock b-roll as the hero.
- Reading the script on screen word-for-word for the whole video.
- Slow 5-second establishing shots.
- Copied competitor boards.
- Generating a full video until the operator says **haan** at the video-generation gate.

## Gate before render

Arena / agent MUST ask:

> Structure + boards ready. Full video generation (VO → scenes → edit → SFX) — **haan**?

Only on explicit **haan** proceed to render pipeline.
