# Self-improvement loop (L16)

If a miss happens:

1. Name the miss precisely.
2. Extract the rule that would have prevented it.
3. Next response must apply that rule at 3x intensity.
4. That miss class must not repeat.

Store rules in `self_improve/lessons.md` (empty until first run).
