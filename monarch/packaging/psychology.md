# Click psychology (use, don’t lecture)

Itches that stop a thumb:

| Itch | Feel | Title/thumb move |
| --- | --- | --- |
| Unfinished | brain hates open loops | cut the last word of the story in the frame |
| Incongruity | WTF two things that shouldn’t share a frame | scale joke / impossible object |
| Forbidden | I shouldn’t know this | “they never show…” only if true |
| Self-threat | this could be me | second person, specific |
| Status secret | insiders know | mechanism, not gossip |
| FOMO | feed will move on | time/rarity without fake countdown |
| Proof shock | number that shouldn’t be real | one number, huge in thumb |

Rules: one itch per package. Pay it in the video. Stacking three itches = spam.

Scrolling thumb is not a critic. It is a lizard. High contrast, one shape, one debt.
