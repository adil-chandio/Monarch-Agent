# Edit grammar (Monarch)

1. **Open (0–3s):** pattern interrupt + unfinished sentence in picture.
2. **Pulse:** every **2–3 seconds** a real scene/clip change. Smooth match-cut. Premium SFX on the cut. First render already at this density.
3. **Match-cut to punch word** in VO.
4. **Silence sting** before the worst/best fact.
5. **Callback:** visual from second 2 returns at the payoff.
6. **Never** a static stickman talking-head for >1.2s without a change.
