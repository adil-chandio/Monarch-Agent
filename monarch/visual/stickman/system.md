# Stickman system — ours

Inspired by explainer-stick language, **not** a PDF replica.

## Figures

- 1.8-head stick, round skull, no face until emotion needs it (one line mouth / X eyes).
- Limbs = single strokes; joints bend for slapstick physics.
- Cast: Hero, Crowd, Authority, Threat, Object-as-character.
- Props: oversized (the important thing is always too big).

## World

- Void stage. Ground line optional.
- One accent color per video (channel lock later).
- Arrows, circles, scribbles = thought, not decoration.

## Motion verbs (only these until we expand)

`enter, point, snap, fall, explode-to-parts, rebuild, chase, freeze, zoom-into-eye, swap-scale, stamp-text`

## Elevation vs typical stickman YouTube

Typical: same bounce, same whoosh, same yellow arrow.  
Monarch: camera grammar + silence + metaphor scale + 2s open that feels like a crime scene, not a lecture.
