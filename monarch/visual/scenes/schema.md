# Scene schema (every beat)

```
id
t_start / t_end          # synced to VO
vo_line                  # exact words on this beat
visual                   # stickman action, not a paragraph
text_on_screen           # 0–6 words, or none
camera                   # punch-in, whip, hold, glitch-cut
sfx                      # one primary hit
emotion                  # curiosity / dread / laugh / WTF / proof
retention_job            # why this second exists
fomo_if_skipped          # what they miss if they blink
```

First scene duration: **2.0–3.0s max**. Must contain the irreversible hook.
