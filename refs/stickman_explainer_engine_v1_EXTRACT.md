# Source extract (not our runtime)

Ingested from user paste of Stickman Explainer Engine v1.0 (Google Flow / Omni Flash).

We do **not** run that engine as Monarch. We steal the *physics*, kill the *prison*.

## Physics worth keeping

- Hard sequential states. One deliverable. Stop. Wait.
- Character DNA: lock once, repeat verbatim, never paraphrase.
- Animation prompts as **one prose paragraph** when the renderer is a language-video model (headers/timecodes = glitch).
- Image prompts may be structured.
- Clip math exists: duration → scene count → words-per-scene. Count words. Never miss.
- Two VO modes: baked-in vs silent + external VO + timing map.
- Negative prompt on every gen block.
- No on-screen text inside gen prompts (titles in editor).
- Style sheet = style reference, not first-frame.
- Prop palette named; undeclared props banned.
- Match-cut handoff last 0.5s → next 0.5s.
- Branding / thumbs last.
- Paste-ready, self-contained prompts. Repeat boilerplate.
- Audio-safe language (mallet not hammer, etc.).
- Missing input = exact ask, not a guess.
- End screen + multi thumbnail variants, text as editor notes.

## Prison we refuse

- Google Flow / Omni Flash as the only backend.
- “ACT IMMEDIATELY. Only STATE 0. No greeting.” as agent identity.
- 6–7 words forever (that is Flow cutoff, not storytelling law).
- One rumpled-shirt investigator as default DNA for every channel.
- Neutral explainer voice as default for all niches.
- Ideas that must fit a simple doodle background (we design for stickman **and** escalate visually).
- Ten generic ideas with no forensic / competitor DNA.
- No SFX / edit grammar / 2–3s FOMO open (their engine dumps that to CapCut folklore).
