### C2. Peak-End doctrine (Kahneman/Fredrickson)
78. Experiences are judged by PEAK + END, not average, not duration
    (duration neglect). Memory = the remembered, not the experienced.
79. Cold-pressor 1993: subjects freely chose to REPEAT a longer pain
    (60 s + 30 s warmer tail) over a shorter one — a better END beat
    more total pain.
80. Colonoscopy replication (N=154): remembered pain = peak + final
    moments; adding a calm 3-min tail improved the memory without
    touching the procedure. Boundary condition: a good END can
    rewrite a bad middle (waiting-line study).
81. Symphony screech: the end doesn't just end the experience — it
    rewrites the MEMORY of all 20 minutes before it.
82. 2026 bridge: satisfaction (#1 signal) is a REMEMBERED judgment →
    design ONE deliberate PEAK + engineer the END (abrupt payoff, no
    fade, no end-signal); loop ending = the end hands the viewer back
    to the start (rewatch re-enters memory). Compression validated:
    memory doesn't reward duration.
    (Honesty note: science solid; the YouTube mapping is synthesis.)

85. Law: hook frames = stickman eyes → CAMERA (stop the scroll);
