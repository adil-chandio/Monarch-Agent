## 1. 🧬 THE BRAIN'S ACTUAL CODE: DOPAMINE IS NOT A REWARD SIGNAL —
IT IS A *SURPRISE* SIGNAL (Schultz's discovery)

The monkey/juice experiments: dopamine neurons fire when reward is
UNEXPECTED. Once reward becomes predictable, they go silent for the
reward itself and fire for the CUE that predicts it. Give a reward
every day — by day 365 the dopamine system barely registers it.

The algorithm your viewers' brains run:
```
RPE = received − expected
RPE > 0  → dopamine BURST (learning + pleasure)
RPE = 0  → silence (no matter how big the reward)
RPE < 0  → dopamine DROPS BELOW BASELINE (dissatisfaction)
```

**The 2025 APA-grade extension that makes this a video weapon:**
information itself is a reward — *information prediction errors*
drive curiosity AND long-term memory. And two asymmetric truths:
- **Positive information** (upbeat/constructive reveals) beats
  negative for both curiosity and memory.
- Curiosity follows the **info-gap curve (Loewenstein): a MEDIUM
  gap peaks. Too small = boring; TOO LARGE = "not my business,"
  curiosity collapses.** The gap must be CALIBRATED, not maximized.

**THE MASTER LAW this produces (the deepest single finding of all
four hunts):**
- HOOK = open a *calibrated medium* information gap ("Polar is
  FAKE?!" works because the viewer knows-and-loves the ranking —
  gap is medium. "This animal you've never heard of did something"
  fails — gap too large).
- PAYOFF = must **EXCEED** the expectation the hook set (+RPE → the
  dopamine burst → the remembered PEAK). A payoff that merely meets
  the promise = RPE 0 = dopamine silence = "meh" memory. A payoff
  below the promise = RPE NEGATIVE = neural dissatisfaction — this
  is the *mechanism* behind bait-and-switch (-30% demotion) and
  satisfaction-survey collapse. Clickbait isn't an ethics problem;
  it's a prediction-error miscalculation.
- EVERY BEAT = a small prediction error (pattern interrupts every
  5–8 s are RPE microdoses; "reset attention" is the behavioral
  readout).

Convergence: Beast's "wow factor", the curve-doctrine's
re-stimulation, peak-end's PEAK — all are prediction-error
engineering. This is WHY those laws work.
